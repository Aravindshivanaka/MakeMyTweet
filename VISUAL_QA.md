# Visual QA Rules

1. No multiple visible scrollbars.

2. Rich Blue Frame must tightly wrap Tweet Card.

3. Tweet Card must visually match reference image.

4. Use proper Twitter/X action icons:

* Comment
* Retweet
* Like
* Views

5. Mobile preview must visually match reference image.

6. Maintain visual proportions:

Sidebar: ~25%

Desktop Preview: ~50%

Mobile Preview: ~25%

7. Empty space should be minimized.

8. Visual accuracy is more important than implementation speed.
