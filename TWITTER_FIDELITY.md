# Twitter/X Fidelity Specification

Target:

Match modern X.com tweet appearance.

Do not imitate old Twitter designs.

---

Tweet Header

Contains:

* Avatar
* Display Name
* Verification Badge
* Optional Custom Badge
* Username
* Timestamp

Single row layout.

---

Tweet Content

Placed directly below header.

Support:

* Multi-line text
* Emojis
* Hashtags
* Mentions

---

Media Support

Support:

* Image
* Video thumbnail

Rounded corners.

Full width.

Optional.

---

Metrics Row

Show:

1. Reply
2. Retweet
3. Like
4. Views
5. Bookmark
6. Share

Icons should visually match X.

---

Spacing

Follow modern X spacing.

Avoid oversized padding.

---

Visual Goal

User should immediately recognize the card as a modern X post.
